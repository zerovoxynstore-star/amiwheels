# AmiWheels Dark Upload

Versi ini sudah:
- Dark premium style
- Upload foto dari galeri HP, bukan link
- Preview foto produk
- Marketplace
- Inventory
- Auto Sold Out
- Restock
- Bukti Pembelian / History Penjualan
- Export CSV

## Cara pasang
Upload ulang 3 file utama ke GitHub:
- index.html
- style.css
- app.js

Setelah commit, buka Cloudflare Pages > Deployments > redeploy.
